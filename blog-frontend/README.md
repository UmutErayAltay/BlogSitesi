# blog-frontend

Blog Sitesi'nin React + TypeScript istemcisi. Projenin tamamı, kurulum adımları ve API
dokümantasyonu için kök dizindeki [README.md](../README.md) dosyasına bakın
(English: [README.en.md](../README.en.md)).

Bu dizin Create React App ile oluşturulmuştur ve `react-scripts` kullanır:

| Komut | Açıklama |
| --- | --- |
| `npm start` | Geliştirme sunucusunu `http://localhost:3000` adresinde başlatır |
| `npm test` | Test koşucusunu etkileşimli izleme modunda başlatır |
| `npm run build` | Üretim derlemesini `build/` klasörüne çıkarır |
| `npm run eject` | Yapılandırmayı `package.json`'a gömer — geri alınamaz |
